# Codart

Backend de una tienda virtual con autenticación, productos, carrito de compras, órdenes y futura integración de pagos.

## Stack

- Node.js
- TypeScript
- Express
- PostgreSQL
- Sequelize
- JWT
- bcrypt
- Vitest

## Arquitectura

El backend seguirá el flujo:

`Route → Controller → Service → Model → PostgreSQL`

## Módulos

- Auth
- Products
- Cart
- Orders
- Payment
- Admin
